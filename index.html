NOWNov 2024 — Present

Chubb Insurance

Senior Data Engineer

Building a modern streaming platform where real-time event data becomes a secure, governed asset that drives underwriting decisions across the enterprise.

  • Designed a shared hybrid ingestion architecture: on-prem Linux server bridges on-prem Kafka and source systems to ADLS Gen2, enabling secure cloud-side Databricks processing — applied consistently across all 3 production pipelines.
  • Engineered ChubbIO pipeline — ingests Thailand Auto Rating claim events (vehicle & claim JSON payloads) from on-prem Kafka via Linux bridge to ADLS Gen2; processes 2,000 files per 6-hour batch through full medallion architecture (bronze → silver → gold) into Snowflake for UW squad reporting; reconciles files received vs files processed for every batch run.
  • Built DuckCreek policy pipeline — hourly Kafka batch captures policy-sold events containing ASYNC IDs; calls secured DuckCreek API per ID to retrieve full XML policy documents; encrypts on-prem via AES-256 (Azure Key Vault-managed) before ADLS transit; decrypts and processes entirely in Databricks memory with zero PII written to persistent storage; tokenizes PII via Chubb native API backed by an isolated on-prem tokenization server; loads structured data to Snowflake. Dual reconciliation: files received vs processed + ASYNC IDs vs XML documents returned. 10,000+ policies warehoused to date.
  • Delivered SQL Server → Snowflake migration via Databricks — 5M+ rows, 25GB of history data including embedded XML columns requiring custom parsing; AES-256 tokenization applied to all PII fields before load.
  • Implemented Chubb-standard AES-256 encryption (Azure Key Vault) and field-level PII tokenization with architectural isolation — Databricks has zero access to the on-prem tokenization server by design, eliminating cloud-side PII exposure.
  • Managed CI/CD deployment and environment promotion across all pipelines using Databricks Asset Bundles (DAB).
